# Malawi Bloom - Marketplace

**The Warm Heart of Africa in Every Petal**

This is a [Next.js](https://nextjs.org) e-commerce marketplace for Malawian flower sellers and buyers. The project showcases a beautiful, locally-focused design with Material Design 3 theming.

## Features

- 🌺 Beautiful hero banner with search functionality
- 🎯 Shop by occasion categories (Valentine's, Weddings, Birthdays, etc.)
- 📱 Responsive design with mobile bottom navigation
- 🎨 Custom Material Design 3 color system with Malawi-inspired palette
- ✅ Verified local seller profiles
- 🖼️ Bento grid layout for trending products
- 🌍 Bilingual support (English/Chichewa)
- 💳 Local payment methods (Airtel Money, TNM Mpamba)

## Design System

- **Fonts**: Source Serif 4 (headings) and Be Vietnam Pro (body)
- **Icons**: Material Symbols Outlined
- **Colors**: Custom Malawi-themed palette with warm oranges and greens
- **Styling**: Tailwind CSS v4 with custom design tokens

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load Source Serif 4 and Be Vietnam Pro fonts from Google Fonts.
